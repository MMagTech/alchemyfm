Stations Table

Name / Mount
Deployed channels from the plugin. Name links to the listener station page.
Queue
Tracks queued, estimated buffer minutes, and pool size. Refills automatically every ~30 seconds when low.
Status
Live / Off plus health: OK, Refill (source issue), or No pool.
On / Off
Disable stops Liquidsoap for that station (mount goes silent). Enable starts it again within a few seconds. Edit programming in AudioMuse, not here.

Appearance

Default Station Theme
Theme new visitors see before they pick their own. Listeners can override it per browser from the station page header.
Artist Biography
When enabled, station pages can show a short artist bio above the visualizer (from Navidrome / Last.fm / Deezer metadata). Listeners can hide or show it with the Artist Bio toggle in the station header.
Heart Playlist
Navidrome playlist used when you heart a track from the listener PWA (home mini-player or station page). The playlist lives in Navidrome — Appearance only stores which one to target.
Operator Sign-In (PWA)
Press and hold the colored logo button (the small square with bars, not the “Alchemy FM” text) for about one second on the home or station page. Sign in inside the installed PWA so the session cookie applies. A quick tap on the logo still goes home. Hearts appear only while your session is active (about 7 days), then you sign in again the same way.

Broadcast (global)

Max Listeners
Icecast client limit across all mounts. Changing it requires Restart Icecast — live streams drop briefly.
Encoding
Format, bitrate, and sample rate for every station. Saving applies to Liquidsoap; stations restart individually.
Crossfade
Seconds to overlap between tracks. 0 = hard cut.

Troubleshooting

  • Missing Album Art — Usually the on-air track could not be matched to a Navidrome ID. Redeploy or refresh from the Channel Designer plugin if metadata looks wrong.
  • Wrong Or Repeating Tracks — Long uptimes: queue.m3u can grow with old entries while the database moves on. Restart the backend or redeploy from the plugin (see docs/TECH_DEBT.md in the repo).
  • Station Silent After Changes — Confirm the station is enabled (On) in the table and check Docker logs for Liquidsoap. Persistent backend log: DATA_DIR/logs/backend.log (inside the app data volume).
  • No Stations in Table — Deploy channels from AudioMuse (Plugins → Alchemy FM). They appear here automatically after deploy.
  • Listeners Stuck After Icecast Restart — Stream epoch bumps automatically; tuned-in web players reconnect within a few seconds.
  • Listener Count Looks High (Safari / iPhone / remote access) — Safari opens a short Range: bytes=0-1 probe before playback. The in-browser player uses /api/stations/{slug}/listen so the backend answers that probe without an extra Icecast connection. Counts can still read 2 if a listener uses the direct mount URL (external player + browser, or two tabs). At home on split ports (web :8080, Icecast :8000) the proxy path is used automatically; behind Traefik on one hostname, older builds preferred the direct mount and inflated counts — ensure the latest frontend is deployed. If counts still look wrong, check backend.log for listen open … active=2.

External Services

Programming comes from AudioMuse. Stream URLs and cover art come from Navidrome. Both must be configured in .env and reachable from the backend container — listeners never connect to them directly.

Restart Icecast?

Live streams will drop for a few seconds while Icecast restarts. Listeners should reconnect automatically once mounts are back.
