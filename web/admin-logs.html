Logs Help

Where to look when something's not working.

Which Log?

Backend
The Alchemy FM app itself — API requests, queue refills, admin actions, errors.
Liquidsoap
The audio pipeline for every station — encoding, crossfades, track transitions, Icecast connection issues from the source side.
Icecast Access
Every listener connect/disconnect to the streaming server, from the server's own perspective.
Icecast Error
Icecast-level problems — source auth failures, listener limit hits, startup issues.

Reporting a Bug

Clear the relevant log first, reproduce the issue, then download it — that keeps the file focused on just the problem instead of everything since the last restart.

Log Level

Controls only the backend's own verbosity. Debug is much noisier and will rotate through the size cap faster — worth turning back down to Info once you're done digging.
