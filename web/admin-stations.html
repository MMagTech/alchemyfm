Designing Channels

Create and edit all stations in the Alchemy FM Channel Designer plugin in AudioMuse (Plugins → Alchemy FM) — CLAP sonic search, lyrics themes, mood clusters, preview with tempo and energy, and living channels that evolve with your library.

Stations List

Deployed channels from the plugin. Name links to the listener station page.
Queue
Tracks queued, estimated buffer minutes, and pool size. Refills automatically every ~30 seconds when low.
Status
Live / Off plus health: OK, Refill (source issue), or No pool.
★ Featured
Pins the station to the Featured row on the home page, up to the current cap. Use the up/down arrows to reorder within Featured or the rest of the list.
On / Off
Disable stops Liquidsoap for that station (mount goes silent). Enable starts it again within a few seconds. Edit programming in AudioMuse, not here.

Troubleshooting

  • Missing Album Art — Usually the on-air track could not be matched to a Navidrome ID. Redeploy or refresh from the Channel Designer plugin if metadata looks wrong.
  • Wrong Or Repeating Tracks — Long uptimes: queue.m3u can grow with old entries while the database moves on. Restart the backend or redeploy from the plugin (see docs/TECH_DEBT.md in the repo).
  • Station Silent After Changes — Confirm the station is enabled (On) in the list and check Docker logs for Liquidsoap. Persistent backend log: DATA_DIR/logs/backend.log (inside the app data volume).
  • No Stations Listed — Deploy channels from AudioMuse (Plugins → Alchemy FM). They appear here automatically after deploy.
  • Listeners Stuck After Icecast Restart — Stream epoch bumps automatically; tuned-in web players reconnect within a few seconds.

External Services

Programming comes from AudioMuse. Stream URLs and cover art come from Navidrome. Both must be configured in .env and reachable from the backend container — listeners never connect to them directly.

Restart Icecast?

Live streams will drop for a few seconds while Icecast restarts. Listeners should reconnect automatically once mounts are back.
