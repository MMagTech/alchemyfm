Admin Help

Operations for managing stations, queues, broadcast, and knowledge settings.

Stations Table

Edit
Open the station form with current settings. Slug cannot change after creation.
Queue
Manually refill the queue when it runs low. Normal operation refills automatically in the background.
On / Off
Disable stops Liquidsoap for that station (mount goes silent). Enable starts it again within a few seconds.
Rebuild
Destructive. Clears the queue and pool, re-imports tracks from the programming source, and rewrites queue.m3u. Use when programming or source settings changed drastically.
Delete
Permanently removes the station, its queue files, and Liquidsoap process.

Creating & Editing Stations

Source Type
Song Alchemy Anchor — pulls tracks from an AudioMuse anchor.
Similar Seed — starts from one library track and plays similar titles.
When Pool Runs Low
Stay In Source — reuse imported pool (no drift).
Similar To Seed — fetch more like the fixed seed.
Similar To Last — follow whatever just played (can wander).
Queue Target / Refresh Below
Target is how many tracks to keep queued. When pending drops below “refresh below,” the backend adds more.
Artist Separation
Minimum minutes before the same artist can play again on this station.
Station Artwork
Fallback image on the station page when the current track has no album art. Upload or URL.

Broadcast (global)

Max Listeners
Icecast client limit across all mounts. Changing it requires Restart Icecast — live streams drop briefly.
Encoding
Format, bitrate, and sample rate for every station. Saving applies to Liquidsoap; stations restart individually.
Crossfade
Seconds to overlap between tracks. 0 = hard cut.

Knowledge

What Listeners See
“Did you know?” trivia on the station page for the on-air track. Only cached facts are shown.
Mode
Off — hidden.
Cached Only — read cache, no new enrichment.
Active — enrich upcoming queue tracks in the background.
Providers
Search uses MusicBrainz, Wikipedia, and DuckDuckGo (free). Ollama is required (OLLAMA_URL, OLLAMA_MODEL). Optional SearXNG via SEARXNG_URL. Restart backend after .env changes.
Clear Cache
Removes all cached facts and cancels pending jobs. Use Active mode to rebuild.

Troubleshooting

  • Missing Album Art — Usually the on-air track could not be matched to a Navidrome ID. Try Queue or Rebuild if metadata looks wrong.
  • Wrong Or Repeating Tracks — Long uptimes: queue.m3u can grow with old entries while the database moves on. Restart the backend or use Rebuild to resync (see docs/TECH_DEBT.md in the repo).
  • Station Silent After Edit — Confirm the station is enabled and check Docker logs for Liquidsoap. Mount changes restart only that station (~1–2s gap).
  • Seed Search Empty — AudioMuse must be running and reachable; hard-refresh admin after backend updates.
  • Listeners Stuck After Icecast Restart — Stream epoch bumps automatically; tuned-in web players reconnect within a few seconds.

External Services

Programming comes from AudioMuse. Stream URLs and cover art come from Navidrome. Both must be configured in .env and reachable from the backend container — listeners never connect to them directly.

Clear Knowledge Cache?

Deletes all cached facts and cancels pending enrichment jobs. Settings and provider URLs are kept. You can re-enrich tracks after switching back to Active.
